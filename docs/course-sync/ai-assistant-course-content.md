# Hinweise fuer KI-Assistenten zur Kursbearbeitung

## Infokaesten

Verwende fuer Infokaesten in Kursinhalten die bestehende Admonition-Syntax:

```md
!!! info Titel des Kastens
Inhalt des Infokastens.
!!!
```

Nutze diese Syntax statt Markdown-Blockquotes wie `> **Hinweis**`, damit
Infokaesten im Kurs und in H5P konsistent gerendert werden.

Beispiel:

```md
!!! info Fuer Einsteiger
Variablen und Funktionsaufrufe solltest du bereits kennen.
!!!
```
