# Logo-Vorschläge für Materialwerkstatt

Die Übersicht `vorschlaege.svg` vergleicht vier Entwürfe, jeweils mit kleiner Icon-Ansicht, heller und dunkler App-Kachel sowie Wortmarke. Die vier nummerierten SVGs sind transparente, skalierbare Originale.

1. **Faltwerk:** Gefaltete Materialbögen bilden ein M. Empfehlung: verbindet Materialien und Gestalten und bleibt als App-Icon kompakt.
2. **MW-Monogramm:** M und W bilden eine durchgehende Spur; der goldene Punkt markiert einen Ansatzpunkt.
3. **Werkbank:** Eine Arbeitsplatte auf M-förmigen Beinen trägt ein geometrisches Werkstück. Der direkteste Werkstattbezug.
4. **Materialbaukasten:** Vier Bausteine bilden ein M: zwei Außenstege und zwei gerichtete Diagonalen. Der untere Einzelblock entfällt. Gleiche Stegbreiten, symmetrische Abstände und eine größere Zeichenfläche verbessern die Lesbarkeit als kleines Icon. `baukasten-verfeinert.svg` zeigt den Vergleich und die Größenprüfung. Auf dunklem Hintergrund werden die Außenstege aufgehellt.

Der überarbeitete Materialbaukasten ist das ausgewählte Standard-Logo. `src/material_ui/static/favicon.svg` wird für das Browser-Icon, die App-Kopfzeile und die Desktop-Installation verwendet. Das Icon der Unterrichtseinheiten ist unabhängig davon auf eine Glühbirne umgestellt.
